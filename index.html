Open Interest Tracker

This page fetches option open‑interest data for three major tickers—QQQ, SPY and SPX—and compares today’s value with yesterday’s. Open interest represents the number of outstanding option contracts that have not been closed or exercised. Exchanges report the data at the end of each trading day.

Notes:

  • Data is fetched from Yahoo Finance’s public options API. You may need to run this page through a local HTTP server (e.g. python -m http.server) to avoid CORS restrictions. Some corporate networks block direct access to the Yahoo API; if you see errors, check your network settings.
  • The app stores the most recent open‑interest values in your browser’s localStorage. Clearing your cache will remove the history.
